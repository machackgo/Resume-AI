# Stage 3I architecture and experimental boundary

This is an additive retrieval correction experiment, not a production RAG freeze or a training stage. Historical Stage 1–3H files are read-only. No model assets or dependencies are replaced.

The structural-extractive-v1 decomposer accepts a typed InformationNeed and retains its original ID and exact text. Components retain deterministic SHA-256-derived IDs, order, original tokens, and conjunct-to-original relationships. It splits recognized coordinated action clauses, shared action objects, and explicit “both” predicates. Necessary numeric/credential qualifiers remain attached. Negation, disjunction, conditions and unsupported conjunctions are preserved rather than expanded. A preserved compound may still be under-decomposed; that is a measured decomposition failure, not a successful atomization. This constrained grammar avoids model-generated entities but is not a general natural-language entailment prover.

Every component uses Stage 3E focused-v1 query construction, the pinned MiniLM model and semantic space, the existing candidate-scoped VectorStore, 20-vector branch budget, active-version filters, and identity reranking validation. Component code accepts no evidence-supplied scope or filters. New queries are embedded on CPU; historical document vectors and identical historical query vectors are reused exactly. Small CPU re-embedding roundoff is recorded separately.

Compound per-component budgets 1, 2, 3 and 5 and global limits 5/6 are evaluated before Qwen. Atomic/unsplit requirements retain the existing five-result allowance so the historical rank-five regression is not silently broken. A fixed experimental cosine floor of 0.20 rejects low-scoring candidates; it is not an entailment threshold and has no production calibration claim. Empty and budget-excluded components have distinct explicit states.

Merging unions exact whitespace-normalized text groups, preserves all source references, and retains per-component rank/score/query IDs. Selection visits each component's first group before its second, continuing until the global group budget is reached. This gives each component an opportunity; it cannot promise a slot when components outnumber slots, and an irrelevant high-scoring neighbor can still occupy one. Group membership is not evidence of support. Raw traces retain source-specific membership; the compact context mapping denotes membership of an exact-text group and its corroborating sources.

Stage 3G's system prompt, support schema, label composition, provenance resolution and untrusted evidence boundary remain unchanged. Added context fields expose generated retrieval components, selected evidence IDs, missing/budget-excluded states, and the explicit non-entailment notice. In the controlled experiment, Qwen's scored atomic claims remain the frozen Stage 3H supplied components. This isolates the retrieval/context correction and does not establish end-to-end quality of automatically generated scoring atoms. The separate decomposition benchmark measures that layer independently. h06's legacy base-weight specificity is preserved for comparison and excluded in a sensitivity analysis.

Retrieval configuration is selected solely by LARGE/XL all-required-components coverage, component survival, evidence record count and budget size, in that order. It is frozen before any Stage 3I Qwen output. No final-answer tuning, output repair, increased generation cap, QLoRA, training dataset, adapter, browser/application workflow or production deployment is authorized in this stage.

Model inference uses one A30 under Slurm, account cs541/partition academic, 8 CPUs/64 GB RAM, at most 10 hours. Existing Qwen3.8-27B assets, NF4/double quantization, BF16 compute, greedy generation, seed 42, thinking disabled and 1,536 output tokens remain identical to Stage 3H. Six infrastructure smoke cases precede LARGE/XL; SMALL/MEDIUM are bounded regression runs. Historical controls are reused, never regenerated. The allocation exits immediately after inference; independent replay runs on CPU.

Limits to the study: one frozen synthetic candidate and repeated distractor templates; authored gold and semantic audit rather than independent human adjudication; a small new supplemental fixture set; a single embedding model and fixed plausibility floor; original Stage 3G ambiguity for multi-chunk evidence IDs remains fail-closed. Report model errors with relevant evidence present separately from residual retrieval losses. Freeze RAG only if the full user-specified gate is met.
