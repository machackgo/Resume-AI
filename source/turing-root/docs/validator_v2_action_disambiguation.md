# Bounded action disambiguation in validator v2

The first full-batch preflight also exposed lexical false positives: `fine-tuned ... using QLoRA` was flagged as new use when the exact supplied source said `fine-tuned ... with QLoRA`; `training in statistics and public policy` grounded to exact degrees was misread as model training. Before the v2 implementation snapshot, bounded rules were added for an explicit instrument adjunct under the same supported primary action and for an education noun phrase whose domain words occur in cited degree/credential fields. An unsupported instrument, a missing educational domain, and actual model-training claims remain rejection controls. These rules do not authorize action escalation, new technologies, credentials, numbers, or dates. The independent semantic critic remains mandatory. All ten repair tests and the complete regression suite must pass. Earlier v1 artifacts and raw teacher outputs remain unchanged.
