# Stage 3H design v1, written before Qwen outputs

Scope: final controlled scale validation only. No training or production retrieval changes.

Four nested histories contain 24/100/500/1500 active chunks, plus one superseded revision and a separately scoped adversarial candidate. Sixteen fixed needs (4 supported, 3 partial, 3 contradicted, 6 unknown) have 20 supplied atomic slots. Authored relation tables predate Qwen; no gold is inferred from model output. Short documents fit unchanged moderate chunks. Twelve deterministic realistic distractor templates model project logs, adjacent methods/actions, job requirements, self assertions, and exact duplicates. This is a single-author synthetic sensitivity study, not production accuracy or independent human adjudication. Exact duplicate corroboration shares truthful relations. Relevant core evidence remains byte-identical across scales.

Reuse Stage 3G system_v2/schema/validation, semantic retrieval budget 20, title-section embeddings, identity reranker and top-3/top-5 group budgets. Full context enumerates all active catalogue records in source order using the same authenticated reference factory; no query-based selection and no truncation. Full-context token counts include all metadata, schema and chat-template tokens. No truncated arm is included.

Single-A30 admission v1 checks actual token count + unchanged 1536 output reservation against the model position limit. It also uses the config-derived KV lower bound: 16 full-attention layers × two K/V × four KV heads × 256 dimensions × two BF16 bytes = 65,536 bytes/token. If KV alone exceeds free VRAM after loading, record FULL_CONTEXT_NOT_FEASIBLE with that operational reason (not a claim about model maximum length). Otherwise attempt real inference. Record OOM separately, with elapsed time and memory; continue smaller-context arms after CUDA cache cleanup. No arbitrary token cutoff, no offloading or multi-GPU escalation. Torch generation/model/quantization settings remain identical. Full long-prompt generation may be expensive; four-hour maximum governs scheduling. Unrun cases remain unrun, never scored as failures.

Primary matrix is 16 needs × 4 scales × 3 arms, reduced only by explicit infeasibility. Alternate arm order by need; process scales ascending. One Qwen load for two infrastructure smoke cases and the final run. Smoke tests check infrastructure, not answer quality. Freeze dataset, implementation, tests, vectors and prepared contexts after smoke and before the controlled run. Save every prompt, token count, raw output, timing and memory peak. No gold changes after smoke.

Metrics retain Stage 3G closed-fixture entailment scoring, with both full-corpus and context-conditional atomic accuracy. Recall/MRR use only needs with authored relevant core evidence; absence needs get null, not fabricated recall. Core evidence survival, dedup crowding and irrelevant/dangerous neighbors are separately measured. The automatic neighbor rate is an upper bound (all records without an authored relation); manually audit meaningful adjacent neighbors. Injection exposure, explicit foreign-ID/canary compliance and suspected label promotion are separate. A wrong label alone cannot prove malicious-instruction compliance. Counterfactual sanitized-evidence probes may diagnose suspects after the frozen primary run, without changing its data or scores.

All candidate B evidence lives in the same root but a separate scope-bound database. Reject scope override and foreign insertion before generation; check all prompts/citations for foreign IDs. Resolve every stored record and every emitted context reference through vector/embedding/chunk/canonical source/native pointer. Rebuild in a separate CPU process using actual embeddings; compare provenance and rankings, reconstruct prompts, decode output IDs and rescore. Replay historical regressions without writing historical artifacts.

Failure categories: INGESTION / DATASET, CHUNKING, EMBEDDING, VECTOR STORAGE, RETRIEVAL, RERANKING, CONTEXT CONSTRUCTION, QWEN REASONING, CITATION, STRUCTURED OUTPUT, SECURITY. Missing evidence is retrieval attribution; wrong reasoning with sufficient evidence is Qwen. The identity reranker introduces no order changes. No proposed fix is included in this experiment.
